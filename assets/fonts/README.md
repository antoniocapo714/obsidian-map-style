# Obsidian Sans (map label glyphs)

SDF glyph ranges for MapLibre, built by `scripts/build-glyphs.mjs`: **Inter** (Regular, Medium, Italic — latin, latin-ext, vietnamese, cyrillic, greek) composited over **Noto Sans** for every script Inter does not cover.

- Inter — SIL Open Font License 1.1, see `LICENSE-Inter.txt`.
- Noto Sans glyphs from [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) — SIL Open Font License 1.1, see `LICENSE-NotoSans.txt`.
